# BotZoneBot

Rich Message playground project, moved into the shared Telegram Cloud Sandbox workspace.

Commands include `/start`, `/help`, `/richdemo`, `/richmd`, `/richlayout`, `/richblocks`, `/richdraft`, `/richmedia`, `/richbuttons`, and `/richentities`.

The shared GitHub Actions workflow deploys this directory when selected as `bots/BotZoneBot`. Keep bot-specific modules inside this folder and do not commit `.tgcloud/` local state or credentials.
